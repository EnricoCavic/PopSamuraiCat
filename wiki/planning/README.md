# Planning

**This folder owns *how we intend to get there*** — the route: order, what blocks what, roughly what
each step costs, and **what each step must prove**. It is built from [[design/README|design]] and
[[decisions/README|decisions]] together, and it changes when a milestone lands and moves what
follows.

**Never contains** the design itself, why a fork was chosen, or an account of work already done. A
plan that absorbs the record of what shipped stops being a plan and becomes a second, worse copy of
[[tasks/README|tasks]].

**A plan's claims about the code are checkable, and go stale fastest.** A route costed against a
system that has since changed is worse than no plan, because it reads as current. Cite
`file:LINE` for anything the plan depends on, and re-read those citations before building on them.

**Empty.** No route has been written yet.

**Full register: [[index]] § *Planning*.** It is the only catalog — this README explains the folder,
it does not list its contents.
